# Весёлая ферма

Консольная игра по лабораторным работам 1–5 по КПО (вариант 3).

Автор: Масюк Алексей, ПО-16.

## Запуск

Нужен Python 3.9+, сторонние библиотеки не используются.

```sh
python3 src/main.py
```

Тесты:

```sh
python3 -m unittest discover -s tests
```

## Что сделано

- **ЛР1** — главное меню (номера пунктов вынесены в константы), настройки: сложность и начальное количество животных каждого вида.
- **ЛР2** — настройки хранятся в `data/settings.json`, файл создаётся при первом запуске. Количество животных хранится в `dict` (Map). Можно добавить новый вид животного и новый корм.
- **ЛР3** — классы `Player`, `Animal`, `Food`. Игра идёт по дням, в день ограниченное число действий: покупка животных и корма, кормление, уход. Каждому виду подходит свой корм.
- **ЛР4** — сохранение в `data/save.json` и загрузка. Вручную сохраняться можно не чаще раза в 30 минут, во время игры раз в 30 минут срабатывает автосохранение. «Загрузить игру» сразу продолжает сохранённую игру.
- **ЛР5** — сытость и счастье животных. Если животное три дня подряд голодает, оно погибает. Корова даёт молоко, курица — яйца, доход зависит от состояния животного.

## Файлы

- `src/main.py` — точка входа
- `src/ui.py` — меню и ввод
- `src/game.py` — игровые классы
- `src/storage.py` — работа с файлами
- `src/config.py` — константы и настройки по умолчанию
- `tests/test_farm.py` — тесты
